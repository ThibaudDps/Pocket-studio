# Pocket Studio

Un petit studio de poche pour ne plus perdre une idée de mélodie.

J'ai toujours un riff ou une ligne de basse en tête au mauvais moment, et ouvrir un DAW prend trop de temps. Ici, j'ouvre, je pose trois notes, j'exporte, et je termine plus tard sur l'ordinateur.

## Dedans

| | | |
|---|---|---|
| 🎹 | Piano roll | Clavier, basse, guitare |
| 🥁 | Batterie | Grille de 16 pas |
| 🎚️ | Pistes | Jusqu'à 8, solo, muet |
| ✂️ | Sélection | Lasso, couper, copier, coller, dupliquer |
| 📤 | Export | Un `.mid` par piste, avec tempo et signature |

## Parti pris

Rapide, gros boutons, une main. Pas de partition, pas de mixage, pas d'effets : tout ça se fait dans le DAW.

Pas de compte, pas de pub. Rien ne quitte le téléphone.

## Installer

1. Ouvre l'adresse de l'app dans Safari (iPhone) ou Chrome (Android).
2. iPhone : Partager → *Sur l'écran d'accueil*. Android : ⋮ → *Installer l'application*.
3. Ça marche ensuite sans réseau.

## Pour les curieux

Une seule page HTML, sans dépendance. Hébergée sur GitHub Pages (Settings → Pages → `main` / root).

## Mises à jour

L'app évolue au fil de l'eau, selon mes envies et les améliorations que j'envisage. Pour installer la nouvelle version, il suffit de revenir sur la page GitHub Pages.
